# Windy 高海拔天气剖面插件

这是一个在 Windy 页面内运行的高海拔天气剖面插件，只保留**单点**和**路线**两种分析方式，用于查看高空天气、地形和沿线云层，并显示 Windy 返回的地面雾／能见度信号。天气、地形只使用 Windy；只有实际返回的有效高度层参与分析，缺测不外推。

Windy 当前已发布版本为 **0.2.1**，仍包含观山模式；开发中的 **0.2.2** 已移除整个观山模式，只保留单点和路线，尚未发布。只有收到用户明确的“发布”指令后，才会上传新版本。地点收藏保存在各自浏览器本地，不会上传或互相同步。

普通用户请阅读[《高海拔天气剖面使用说明》](使用说明.md)，了解安装、单点与路线分析及数据限制。

## 给朋友使用

本地开发地址 `https://127.0.0.1:9999/plugin.js` 只能用于开发者自己的电脑。要让朋友安装，需先把插件发布到 Windy 托管，再分享生成的私有插件链接。Windy 发布指南说明私有插件链接可分享给朋友；`private: true` 表示不在公开插件库展示，不限制知道安装地址的人加载插件。发布前需在 GitHub 仓库配置 `WINDY_API_KEY` Actions secret，并手动运行发布工作流。Windy 服务、商标、天气数据及其他内容仍受其各自条款约束。

当前 Windy 托管的 0.2.1 地址（仍含观山模式）：

`https://windy-plugins.com/16679985/windy-plugin-high-altitude-profile/0.2.1/plugin.min.js`

在 Windy 的插件安装页选择 **Load plugin directly from URL**，粘贴该地址即可；不需要开发者模式。私有直链按版本区分，发布新版本后请使用新地址更新。

GitHub Actions 的验证工作流不会向 Windy 上传插件；发布工作流需使用仓库的 `WINDY_API_KEY` secret，严禁把密钥写入源码、README 或提交记录，也不要发给朋友。

## 开发和加载

1. 在项目目录运行 `npm install`。
2. 运行 `npm start` 并保持终端运行。开发服务器在 `https://127.0.0.1:9999` 提供 `dist/plugin.js`。如果提示 9999 端口已被占用，说明已有开发服务器在运行，直接使用它即可，不要再开第二个。
3. 在 Windy 开发者模式中，将插件脚本地址设为 `https://127.0.0.1:9999/plugin.js?v=0.2.2`，然后刷新 Windy 页面或关闭并重新打开插件。只运行 `npm start` 不会替换已经载入页面的旧脚本；更新源码后需使用新的版本参数并重新载入。插件面板标题下会显示当前已载入版本，方便确认是否更新成功。

## 单点天气

- 点击 Windy 地图选择地点，或粘贴奥维坐标。系统按奥维前缀自动处理：中国大陆坐标使用 `g经度,纬度` 并转换为 WGS-84 后查询；境外坐标不带 `g`，按输入原值查询，不再要求手动选择地区。
- 插件自动读取地形和当前模式的点预报。可以在 ECMWF 与 ICON 之间手动切换，并选择 Windy 当前时刻或可用预报时刻。
- 新版点预报会读取 Windy v3 返回的 `header`、`meteogram`、`airgram` 和 `sounding` 中的逐层字段；没有返回至少两个相邻高度层的同变量有效值时，插件会尝试 Windy SDK 保留的旧版兼容接口。Windy 官方已将此接口标记为弃用，插件会在界面和诊断摘要中明确标出。只有高度、没有温湿风云数值的响应不算可用天气剖面。图表只连接接口实际返回且有位势高度的模式层，不用气压推造海拔。
- 天气请求成功或失败后都可复制数据诊断摘要，用于排查缺层或空曲线。摘要只含模式与来源、字段名、数组形状、字段有效数量和解析能力，不含天气数值或坐标；若 Windy WebView 不允许剪贴板写入，插件会尝试兼容复制，并在失败时展示可手动选取的文本。无可用剖面时也会保留新版和兼容接口的字段形状信息。
- 0.1.57 起摘要按当前图表使用的预报时刻统计，并给出各变量的有效绘图点数和实线段数；可据此区分数据解析正常但页面未显示、以及当前高度层不足以连线。
- 0.1.58 起单点和路线图的气象实线直接带有 SVG 描边样式，避免线条显示依赖组件级颜色变量。
- 0.1.59 起诊断摘要会区分实际绘制的温度、相对湿度、风速、云量曲线，以及仅在数值表中展示的露点、风向数据，避免把未绘制的图表误报为 0 个数据点。
- 0.1.60 修复路线图的键盘高度控制：方向键、翻页键、Home 和 End 都以当前查询海拔为基准。
- 0.1.61 在单点与路线垂直趋势图标题中显示真实有效海拔范围和有效点数，让 0–9000 米图轴内的缺测区间更容易辨认。
- 0.1.62 改善路线剖面可读性：天气色带只覆盖实际分析点，图表比例和坐标留白更清楚。
- 0.1.63 移除无人机天气评级、阈值设置、路线风险汇总和离地高度查询；查询高度统一使用海拔（MSL）。
- 0.1.64 将 Windy 插件显示名称更正为“高海拔天气剖面”。
- 新版接口摘要会记录本次请求的 `include` 项和 Windy 实际返回的字段组；由此可区分“插件没有请求该组”“Windy 未返回该组”和“字段组存在但数组为空”。摘要不包含天气数值或坐标。
- 如果 Windy 的 meteogram、airgram 或 sounding 响应包含 surface 字段，会将该层的温度、露点、湿度、风或云量按模式地形高度单独显示；没有返回的变量继续标为缺测，不将它们当作气压层。
- 同一地点、模式、预报间隔和请求类型的成功天气剖面会在插件内存中缓存 5 分钟，最多保留 48 份；关闭插件后清空，不写入磁盘。地形读数也只在当前插件会话内复用。
- 全屏来源栏区分 Windy 点预报接口与 Windy 旧版兼容接口（官方标记弃用）。接口回传模式名时标为 Windy 响应模式；未回传时按请求模式归属并明确标注“Windy 响应未标注模式名”；若响应明确标注了其他模式，则丢弃该响应并尝试旧版兼容接口。
- 全屏剖面图展示海拔 0 至 9000 米范围内实际返回的温度、露点、相对湿度、风速和逐层云量。主数据中的近地面温度和风按模式地形海拔定位；不会误放到海拔零米。可输入一个任意目标高度，也可同时输入最多 200 个不等间隔高度，或按起止范围和间隔查询；还可在图上拖动选高度。点按彩色数据点会跳到该模式层原始高度并显示读数。地形以上模式层用彩色实线表示，可用于天气查询；地形以下原始模式层以灰色虚线保留垂直走势，并在表格标注“仅模式参考”，不参与插值或云区判断。缺测字段和不连续的模式层仍断开显示，不补造趋势；相同海拔的重复原始值会分别列出，不误当成垂直趋势；可一键跳到最近的有效层查看原值。
- 单点可选填地点实际海拔，覆盖 Windy 平滑地形值并重新过滤地形以下的模式层；查询海拔与地形海拔分开设置，也可一键把查询海拔设到当前地形高度。
- 读取新地点或地形不会自动改动查询高度；若所选海拔低于地形，会明确显示无效原因。需要时可手动点“查询该点地形高度”或选择最近有效层。
- 按海拔范围查询的起止高度可编辑，采样间隔默认为 250 米，可设为 50–2000 米；会保留指定终点，且只对有效模式层范围内插值，不外推。
- 如果 Windy 点预报直接返回地面能见度，会标为“地面能见度”显示；不会把地面值当作高空能见度。
- 单点和路线摘要显示地面雾／能见度信号，依据 Windy 地面水平能见度、可用的雾天气现象码与近地层温湿条件。低能见度或近饱和只提示地面雾况，不代表高空能见度；字段缺失时保持资料不足。
- 单点、路线各分析点和选中的路线点都会明确显示目标高度能见度未提供；地面能见度不会代替高空值。
- 如果响应包含低云、中云、高云汇总字段，会显示其直接值；缺少这些字段时不从逐气压层云量冒充汇总。地面阵风单独显示，并明确标为地面字段。
- 棕黄色区域表示地形以下。灰色虚线显示该区域内 Windy 返回的模式原始层，仅帮助观察模式垂直变化，不代表当地地形下方存在有效空气天气。查询、插值、云区判断仍只使用地形以上数据。连续有效高度层之间才画可查询实线；只有一个有效层时显示其海拔和原值并说明无法形成趋势线；缺测区间保留空白。
- 云层信息优先显示 Windy 直接返回的云底和逐层云量。连续非零云量层归为同一模式云带；上下边界以相邻清空层和有云层的中点估算，边界不完整时不计算厚度，并明确标记为估算。相对湿度达到 90% 的连续区段单独标记为“可能云区估算”，不代表实测云边界或云概率。海拔重复的模式层保留在原始数值表中，但不参与连续云带边界推算。
- 云量、云厚度、湿度、温度和风速图采用对比更强的分档色带；紫斜纹专门表示湿度推算的可能云区，灰斜纹表示缺测或边界不完整，0% 模式云量保持透明。颜色只是数值类别标记，需结合图例和采样来源解读。
- 单点或路线分析点满足“温度不高于 0°C 且有云量或高湿信号”时，会标出零下云层提示；它不代表实际结冰，也不估算结冰强度。
- 有相邻有效温度层跨越 0°C 时，会估算零度层高度；多次穿越会分别列出，缺测处不连线、不外推。该值是模式层间线性估算，不是观测到的冻结层。

## 路线天气

- 切换到路线模式后，按顺序点击起点、转折点和终点。路线不自动规划道路。
- 路线点名称可以在点位列表中编辑；添加或撤销路线点时，未自定义名称会自动更新为起点、转折点或终点。重命名只更新显示，不会清除或重新请求该点的天气数据。
- 默认按累计距离约每 5 千米采样天气，可选约 2/10 千米或按点数采样；等距网格最多 61 点，长路线会增大间距，用户点选的转折点始终保留。模式云量和厚度图支持连续云区估算及仅采样点对照，绿色海拔线可上下拖动。
- 路线天气请求完成后可展开逐点数据诊断，单独复制或一次复制全部分析点的字段名、数组形状和能力状态，便于排查空图；摘要不含天气数值或坐标，剪贴板不可用时可手动复制。
- 路线剖面下方按先后顺序并排对照所有分析点的坐标、路线距离、地形与查询海拔、温度、湿度、风向风速、查询高度云量、直接云底和地面降水。点选卡片即可切换到该点垂直剖面；未读点与缺测值仍保留在列表中。
- 分别读取路线地形和天气。地形采样除约 250 米间距的路线点外，还会精确纳入每个用户转折点；侧栏显示五位小数坐标及对应的 Windy 地形高度或缺测状态。全屏路线剖面以距离为横轴、海拔为纵轴，支持模式云量、云层厚度估算、湿度、温度、风速和高湿可能云区显示。模式云带与高湿可能云区分别标注来源；长路线采样可取消，取消时会终止尚未完成的 Windy 请求。地形采样密度不代表气象模式分辨率。
- 点击路线分析点可查看该点 0–9000 米的温度、湿度、风速和云量垂直曲线，以及对应高度层表格；拖动任一单点曲线会同步路线查询高度。查询高度低于该点地形或缺测时，会显示最近有效层的温湿风云原值，并可一键把查询线移到该层。只有一个有效层或层间有缺测时，会把实际高度和值直接显示在图表上方，同时保留断线，不伪造趋势。沿线地面降水单独显示，不解释为高空降水。温度视图在各个实际天气分析点标出 0°C 温度层估算圆点；圆点之间不连成未经采样的连续冻结层。

## 数据边界

插件只使用 Windy 当前所选模型和 Windy 点预报/地形接口，不混用 ECMWF 与 ICON 字段，也不接入外部天气源。每个地点、模式和时刻可用的高度层不同；少于两个连续有效层时无法绘制趋势线，插件只显示已有点值和缺测原因。气象模式估算不等于现场实测。

插件只提供天气数据分析，不输出飞行安全或适飞结论。当前版本不提供 ECMWF/ICON 差异比较、预报动画、数据导出或外部报告。插件适合个人或小范围在 Windy 页面内使用。
